# Поиск и извлечение (Retrieval)

Логика поиска, ранжирования и взаимодействия с векторными базами данных, обернутая в кастомные классы LangChain.

## Скрипты
* **`rag_qdrant.py`** — содержит `RegLabQdrantRetriever`. Имплементирует оптимизированный гибридный поиск:
  1. Опциональный HyDE.
  2. Векторный + лексический поиск `child` чанков.
  3. Реранжирование `child` чанков через Cross-Encoder.
  4. Извлечение полных `parent` документов для лучших кандидатов.
  5. Сортировка Lost-in-the-Middle (LITM) для удержания внимания LLM.
* **`rag.py`** — аналогичный гибридный ретривер, но адаптированный под ChromaDB (с ручным управлением BM25-индексом).
* **`hyde.py`** — генерация Hypothetical Document Embeddings. LLM (например, в стиле тех. писателя РегЛаб) генерирует гипотетический ответ на вопрос, чтобы искать по его вектору, а не по исходному запросу.
* **`bm25_utils.py`** — утилиты для создания, сохранения и загрузки лексического индекса BM25. Включает токенизацию и лемматизацию через `pymorphy3`.
