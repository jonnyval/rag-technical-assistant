# `src/retrieval`

Модуль отвечает за поиск, rerank и извлечение parent-документов из векторных баз.

## Основные файлы

- `dual_retriever.py` - основной production retriever. Выполняет отдельный поиск по документации и по тикетам, ранжирует child-чанки, достает parent-документы и сохраняет признак источника `db_source`.
- `rag_qdrant.py` - базовый Qdrant retriever для одной базы: hybrid search, CrossEncoder rerank, parent document retrieval и LITM-сортировка.
- `hyde.py` - генерация гипотетического документа для экспериментального HyDE-поиска.
- `bm25_utils.py` - вспомогательная логика для лексического поиска и BM25.

## Текущая стратегия

Для сценария поддержки используется раздельный поиск:

1. `retrieve_docs(query)` ищет только по документации.
2. `retrieve_tickets(query)` ищет только по историческим тикетам.
3. `RAGEngine` форматирует эти результаты разными блоками, чтобы модель не смешивала справочную информацию и реальные обращения.

Фильтр по оборудованию в основном поиске отключен намеренно: часть документации релевантна сразу нескольким линейкам оборудования.
