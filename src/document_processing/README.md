# Обработка документов (Document Processing)

Модуль отвечает за парсинг исходных данных (DOCX, HTML, JSON), очистку, извлечение метаданных и подготовку чанков для индексации в векторные базы.

## Скрипты
* **`parsers_qdrant_with_llm.py`** — основной парсер технической документации. 
  * DOCX: использует `mammoth` для конвертации в HTML, собирает таблицы и списки в Markdown, сохраняет иерархию заголовков.
  * HTML: чистит от навигационного шума, определяет библиотеку (PsTechMT, PsBase и др.) и оборудование.
* **`parsers_tickets*.py`** — семейство скриптов для парсинга обращений в техподдержку. Включает агрессивную фильтрацию PII (ФИО, телефоны, email) и использует LLM для генерации саммари (Симптомы/Решение). Разделяет тикет на документы типа `card` (переписка) и `fact` (решение).
* **`metadata_extractor.py`** — утилита для обогащения чанков. Отправляет куски текста в локальную модель (через Ollama) для генерации списка ключевых слов и потенциальных вопросов, на которые отвечает текст.
* **`reindex_with_prefix.py`** — скрипт миграции. Читает `parents.db` (SQLite), нарезает на `child` чанки, добавляет префикс для instruction-tuned моделей (например, Qwen3) и переиндексирует в новую коллекцию Qdrant.
