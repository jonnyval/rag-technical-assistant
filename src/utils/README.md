# `src/utils`

Сервисные инструменты для диагностики, проверки окружения и анализа баз.

## Файлы

- `analyze_keywords_qdrant.py` - анализирует частотные термины и метаданные в Qdrant/parent-store.
- `check_db_tables.py` - проверяет структуру SQLite-хранилищ.
- `check_models.py` - проверяет доступность моделей и API-ключей Groq, Gemini и GigaChat.
- `check_structure_prj.py` - печатает дерево проекта с исключением служебных папок.
- `inspect_db.py` - показывает состояние Qdrant или ChromaDB, количество документов и примеры чанков.
- `profiler.py` - контекстный менеджер `TimeProfiler` для логирования времени выполнения этапов пайплайна.
- `read_logs.py` - удобное чтение и просмотр логов.

Эти утилиты не являются production API, но помогают быстро понять состояние индекса, конфигурации и производительности.
