# Утилиты (Utils)

Инструменты для диагностики, дебага и мониторинга состояния системы и баз данных.

## Скрипты
* **`analyze_keywords_qdrant.py`** — анализирует базу `parents.db` (SQLite), фильтрует стоп-слова и выдает ТОП-30 терминов для каждого типа оборудования.
* **`check_db_tables.py`** — быстрая проверка наличия таблиц в хранилище SQLite.
* **`check_models.py`** — проверяет доступность API-ключей и выводит списки доступных LLM моделей для провайдеров Groq, Gemini и GigaChat.
* **`check_structure_prj.py`** — выводит дерево директорий проекта (игнорируя `.git`, `venv`, `__pycache__`).
* **`inspect_db.py`** — инспектор векторных баз. Показывает общее количество чанков в Qdrant или ChromaDB и выводит пару случайных семплов вместе с метаданными.
* **`profiler.py`** — содержит класс `TimeProfiler`. Контекстный менеджер для логирования времени выполнения отдельных этапов пайплайна (генерация HyDE, поиск Qdrant, реранжирование). Отключается через конфиг.
