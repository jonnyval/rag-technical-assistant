# Исходный код (Source)

В этой директории находится базовая конфигурация системы и инициализация логгера.

## Файлы
* `config.py` — класс `Config`, обеспечивающий единый доступ к настройкам из `config.yaml` и секретам из `.env`. Управляет переключением активных БД, выбором моделей (от Groq до Ollama) и параметрами поиска.
* `logger.py` — настройка ротируемого логирования (`RotatingFileHandler`). Записывает детальные события в `data/logs/rag_system.log` и выводит основные статусы в консоль.
