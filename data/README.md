# `data`

Рабочая папка для входных данных, промежуточных файлов, логов, кешей и локальных SQLite-хранилищ.

Сюда обычно попадают исходные DOCX/HTML/JSON, выгруженные тикеты, временные изображения, parent-store, hash registry и логи. Большая часть содержимого является локальным состоянием пайплайна и может отличаться на разных машинах.

Перед удалением файлов проверь, не используются ли пути в `config.yaml`.
